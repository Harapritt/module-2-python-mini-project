# Student Grade Calculator

## Module 2: Python Mini Project

This project is a beginner-friendly **Student Grade Calculator** developed using Python.

The project allows the user to enter a student's name and marks for multiple subjects. It then calculates the total marks, average marks, percentage, and corresponding grade.

## Objectives

* Apply basic Python programming concepts in a practical project.
* Practice variables and data types.
* Use user input.
* Apply conditional statements.
* Use loops and lists.
* Create and use functions.
* Perform basic mathematical calculations.
* Practice problem-solving using Python.

## Features

The Student Grade Calculator can:

* Accept the student's name.
* Accept marks for multiple subjects.
* Calculate total marks.
* Calculate average marks.
* Calculate percentage.
* Determine the student's grade.
* Display a summary of the student's results.

## How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open a terminal or command prompt in the project folder.
4. Run the following command:

```bash
python student_grade_calculator.py
```

5. Follow the instructions displayed in the terminal.
